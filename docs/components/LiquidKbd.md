# LiquidKbd

Use LiquidKbd in a React client component. The example below uses the exported library API.

## Example

```tsx
"use client";

import { LiquidKbd } from "@justfrenzy/liquid-glass";

export function LiquidKbdExample() {
  return (
    <LiquidKbd>Ctrl + K</LiquidKbd>
  );
}
```

Browser imports load styling automatically. For Next.js, keep interactive state and handlers inside a client component. See [getting started](../getting-started.md).
