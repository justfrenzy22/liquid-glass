## Compatibility names

Legacy `LiquidNextUI*` exports remain aliases of their corresponding `Liquid*` components. The short names above are recommended for new code. `SolidCard`, `FinderTable`, `LiquidForm` and `LiquidActionButton` are documented separately. Helpers such as `toast` and `parseColor` are functions, not visual components.

The guides are generated from the current public TypeScript signatures with curated examples. Regenerate with `npm run docs:generate` and validate examples with `npm run docs:check`.
